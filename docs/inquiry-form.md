# Contact inquiry form ("Have us call you back")

- **Google Form:** the contact inquiry form, id `1FAIpQLSdlbJCiaAE1h2VVLcF0mUPG_6SKAs34IR0Ipu_DHATetEX-lg`. Public: https://docs.google.com/forms/d/e/1FAIpQLSdlbJCiaAE1h2VVLcF0mUPG_6SKAs34IR0Ipu_DHATetEX-lg/viewform. The id may be written here and in the check script, never on a page.
- **Site:** `src/components/ContactForm.astro`, the `#contact` section of `/` and `/es/`. Every field is required except "Anything else?", plus the consent checkbox (not sent to Google). `?program=<program id>` preselects the program dropdown (`?program=digital-literacy` picks Digital Literacy Training).
- **Spam check (Worker + Turnstile):** the page never talks to Google. It renders the Cloudflare Turnstile widget (site key `0x4AAAAAAFABG_uSmI7QN2sd`, the same as the other public forms) above the submit button, carries a `website` honeypot, and POSTs the `entry.*` fields plus `cf-turnstile-response` with fetch to `https://mmt-signup.mercermedtech.workers.dev/inquiry-submit`. The `mmt-signup` Worker (source `workers/mmt-signup/worker.js`, school Cloudflare account) verifies the token (hostname must be mercermedtech.com, www.mercermedtech.com, localhost or 127.0.0.1), drops posts that fill the honeypot, forwards only `entry.*` fields to the formResponse URL in the Worker variable **`FORM_ACTION_INQUIRY`** (plain text, set in the dashboard: Workers, mmt-signup, Settings, Variables and Secrets), and answers `{ok:true}` or `{ok:false,error}`. Allowed origins: https://www.mercermedtech.com, https://mercermedtech.com, http://localhost:4321, http://127.0.0.1:4321. Google answering 400 (a required question missing) comes back as 422 `rejected`; the page then shows its "We could not send that" message and the button works again. The Google Form address must not appear in any built page; `npm run check:form` fails if it does.
- **Responses** land in the form's Responses tab, and a copy goes to the staff portal's inbox (mercermedtech.com/admin) as source "Contact form". The Worker makes the copy only after Google answered 200, in the background, with the secret `INGEST_SECRET`; a failed copy is logged in the Worker logs and the reader never sees it. In the inbox the answers read Name, Phone, Email, Program, Best time to call, Message; the language and page come from the page the form was sent from.

- **To add a choice:** 1) add it in the Google Form first, spelled exactly; 2) on the site, a program is a `formOption` in `src/data/programs.ts` (with its name in both languages) and a best time is a value in `BEST_TIME_VALUES` there plus its label in `home.contact.bestTimeOptions` in `src/i18n/en.ts` and `es.ts`; 3) add the value to `PROGRAM_VALUES` or `BEST_TIME_VALUES` in `scripts/check-form-contract.mjs`; 4) `npm run build && npm run check:all`.
- **Changing a question** in Google can change its entry id: re-read the ids from the public form (`FB_PUBLIC_LOAD_DATA_`) and update the component, the check script, the label map (`COPY_FORMS.inquiry` in `workers/mmt-signup/worker.js`, then redeploy the Worker), and this note.
