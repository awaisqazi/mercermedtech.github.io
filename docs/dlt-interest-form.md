# Digital Literacy interest form

- **Google Form** "Digital Literacy Training: interest form", owned by mercermedtech@gmail.com. Edit: https://docs.google.com/forms/d/1wkv2B-7blx5vkuqHNXmE7XLzJc6SWst6MoDSpv-6CpE/edit · Public: https://docs.google.com/forms/d/e/1FAIpQLSdt6Zl1Ecv49ALSWxAAtiOkWBLQJ2vV81lgyuCt6CSUGb4xnA/viewform
- **Site:** `src/components/DltInterestForm.astro`, on `/` and `/es/` (Tech column, `#dlt-interest`) and `/digital-literacy/` and `/es/digital-literacy/` (`#interest`). Required: name, plus phone or email (checked by the page script).
- **Spam check (Worker + Turnstile):** the page never talks to Google. It renders the Cloudflare Turnstile widget (same site key as the sign-up form, `0x4AAAAAAFABG_uSmI7QN2sd`) and POSTs the `entry.*` fields plus `cf-turnstile-response` with fetch to `https://mmt-signup.mercermedtech.workers.dev/interest-submit`. The `mmt-signup` Worker (source `workers/mmt-signup/worker.js`, school Cloudflare account) verifies the token (hostname must be mercermedtech.com, www.mercermedtech.com, localhost or 127.0.0.1), forwards only `entry.*` fields to the formResponse URL in the Worker variable **`FORM_ACTION_INTEREST`** (plain text, set in the dashboard: Workers, mmt-signup, Settings, Variables and Secrets), and answers `{ok:true}` or `{ok:false,error}`. Allowed origins: https://www.mercermedtech.com, https://mercermedtech.com, http://localhost:4321, http://127.0.0.1:4321. Google answering 400 (a required question missing) comes back as 422 `rejected`. The Google Form address must not appear in any built page; `npm run check:form` fails if it does.
- **Responses** land in the form's Responses tab (no Sheet linked yet; use "Link to Sheets" to add one). "Submitted from" says which page and language.

- **To add a choice:** 1) add it in the Google Form first, spelled exactly; 2) add `{ value, label }` in `DltInterestForm.astro` with the label in `src/i18n/en.ts` and `es.ts` (`dltInterest.form`); 3) add the value to `INTEREST_CHOICES` in `scripts/check-form-contract.mjs`; 4) `npm run build && npm run check:all`.
- **Changing a question** in Google can change its entry id: re-read the ids from the public form (`FB_PUBLIC_LOAD_DATA_`) and update the component, the check script, and this note.
